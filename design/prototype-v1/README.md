# RxPlayer 产品原型 01

**状态：待用户审核。** 此版本用于讨论页面、视觉层级与主要交互，不是已确认的产品设计或可用的在线播放器。

## 审核入口

打开 `index.html`；若浏览器限制本地字体，使用以下本地预览方式：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory design/prototype-v1
```

在浏览器打开 `http://127.0.0.1:8765/`。审核工具栏可以切换 Android / Windows、深浅主题及搜索结果 / 起始页 / 无结果 / 网络错误 / 登录失效场景。

首次交付版本使用纯本地的 HTML、CSS 和 JavaScript 表达设计，不改变已确定的 Kotlin / Compose Multiplatform 产品实现路线，不依赖其他播放器的 UI。全部曲目、账号和操作均为演示：不联网搜索、不读取剪贴板、不登录、不播放音频、不收集数据；刷新或重置后恢复示例状态。

## 建议审核顺序

1. 在两个平台切换搜索、音乐库和设置，判断导航结构是否符合使用习惯。
2. 搜索页选择三个音源，输入“夜航”搜索；输入其他词查看无结果；在审核工具栏比较错误和登录失效状态。
3. 点击曲目模拟播放，点击迷你播放器的曲目信息展开；检查播放 / 暂停、拖动、切歌、收藏、队列和收起。
4. 打开曲目的更多菜单，尝试下一首播放、加入队列和添加到歌单；在音乐库检查收藏、最近播放、歌单详情及新建歌单。
5. 在设置中切换主题和播放页配色，查看账号未连接 / 已连接的示意状态。
6. 使用 Tab、Enter / Space 和 Esc 检查焦点及弹层；桌面在非输入、非按钮焦点下按空格模拟播放 / 暂停。

链接输入展示来源识别和暂时无法获取内容的反馈，不把任意链接伪装成某一首演示曲目。原型没有接入真实链接元数据。

## 本版设计提案

| 部分 | 提案 |
|---|---|
| 一级导航 | 搜索、音乐库、设置；正在播放和队列作为任务面板 |
| 搜索 | 顶部 contained search，独立音源单选；结果使用紧凑列表，保留作者、内容类型和时长 |
| Android | 单内容区域、底部导航及迷你播放条；展开播放页、队列和曲目菜单；搜索输入时增加内容空间 |
| Windows | 导航轨、内容区域、播放队列辅助面板及底部控制条；窄窗口隐藏辅助面板 |
| 音乐库 | 收藏、歌单、最近播放；歌单支持详情与新建示意 |
| 设置 | 外观、音源账号及恢复播放位置说明 |
| 状态 | 已暂停与正在播放分别表达，使用示例曲目已知时长；搜索错误与当前播放任务分离 |

## Google 规范与产品决策

规范来源：

- [Google Material 3 / Expressive](https://m3.material.io/)。
- [m3-expressive 技能](https://github.com/abhixv/google-m3-expressive-design-skill/tree/main/skills/m3-expressive)：`tokens.md`、`components/buttons.md`、`components/input.md`、`components/navigation.md`、`components/containment.md`、`layout.md`、`interaction.md`、`shape.md`、`platforms.md`。
- [Google Material Symbols](https://developers.google.com/fonts/docs/material_symbols)。
- Material3 `1.9.0-alpha04` 发布源码中的 `ColorLightTokens.kt`、`ColorDarkTokens.kt` 与 `PaletteTokens.kt`：本版深浅色基线角色值的来源，不从之前播放器项目取色。

本版采用的规范依据：

- 使用角色成对设置正文、表面、主操作及选中状态颜色；导航采用 surface container，内容采用 surface。
- 字号使用角色对应的 12 / 14 / 16 / 22 / 28 sp 比例，强调样式按角色增加字重；标志及原型审核工具栏属于自定义品牌 / 审核界面。
- 圆角使用 8 / 12 / 20 / 28 / 32 / full 等尺度；紧凑曲目容器与封面保留嵌套层级。
- 主要按钮采用按压形状变化；颜色变化使用无过冲效果曲线；支持 `prefers-reduced-motion`。
- 浏览器中的按压形状演示采用技能给出的 fast spatial 曲线回退。它用于本次设计表达，不宣称是 Compose 原生弹簧或手势动效的最终实现。
- 进度滑块参考 XS token：16 dp 轨道、44 dp 高 / 4 dp 宽滑块；交互区域保留至少 48 dp。图标通过 Google Material Symbols 的 FILL 轴表达选中状态。

以下是 RxPlayer 的设计决策，不是 Google 发布的产品尺寸要求：

- 初版以 Material 基线紫色系审阅信息结构和层级，不将该配色视为用户已确认的品牌色。
- Android 审核画框约 412 × 876 CSS px，Windows 审核画框高度约 780 CSS px；这些是预览尺寸，不是目标设备限制。
- 桌面队列面板宽 292 CSS px；预览页面窄于 1080 CSS px 时收起辅助面板。最终原生应用按实际可用空间及官方布局指导实现。
- 页面文案、示例曲目、队列组合、歌单名称、封面图形与信息架构均为本轮待审核提案。
- 封面使用自行绘制的几何图形，不作为官方 Material shape 图库的替代品或标准形状声明。

## 验证与边界

2026-10-28 浏览器自检记录：

- 搜索、三个音源切换、无结果、网络错误重试、登录失效入口、链接来源识别与不支持链接反馈通过；未调用在线服务。
- 模拟播放 / 暂停、播放页、收藏、队列操作、新建歌单和添加曲目、深浅主题切换通过。
- 320 / 390 CSS px 手机预览与 900 / 1440 CSS px 桌面预览无页面水平溢出；手机播放弹层在画框内，桌面辅助队列按可用空间收起 / 展开。
- 检查主要可见控件至少 48 CSS px 交互区域；桌面非输入 / 非按钮焦点下空格播放 / 暂停、弹层 Tab 循环、Esc 关闭和焦点恢复通过。
- 深浅主题各检查 5 组主要文字颜色对，最低对比度约 6.44:1；本地字体正常加载，减少动态效果偏好生效，最后检查未出现浏览器控制台错误。

原型检查只针对浏览器中的设计表达、交互和布局，不代表 Android / Windows 原生产品功能已经实现或验收通过。不把这版设计视为用户已批准；用户审核意见将成为下一版修订依据。

本轮未构建原生应用，也未验证真机软键盘、系统返回手势、屏幕阅读器或真实音频。审核画框中的系统栏属于示意，不承担实际系统操作。
