# RxPlayer 产品原型 02

状态：浏览器自检已完成，待用户审核。原型 01 保留作为对照；本次不改变 Compose 工程或产品功能实现。

## 打开与审核

在仓库根目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory design
```

打开 `http://127.0.0.1:8766/prototype-v2/`。工具栏可以切换 Android / Windows、主题和搜索异常场景，点击“查看播放页”直接检查主要视觉场景。右下角可以返回原型 01 比较。

首次审核可直接打开 `http://127.0.0.1:8766/prototype-v2/?view=player`，从主要修订的播放页开始。

建议依次审核搜索 → 播放页 → 音乐库 → 设置。关注主操作是否突出、封面与文字是否协调、连续分组是否清楚，以及深浅主题是否都舒服。

## 本轮修订

- 搜索页：更明确的标题层级、最佳匹配区、连续的结果分组；最佳匹配区域用于快速播放，全部结果保留完整版本列表。
- 播放页：非对称封面画框、带文字的主播放操作、主次按钮尺寸对比；暂停 / 播放切换影响按钮和画框形状。Android 使用单列，Windows 在足够空间内使用封面 / 控制双列。
- 音乐库：收藏总览、播放收藏入口和封面组合；保留收藏、歌单与最近播放。
- 设置：按外观、播放和音源账号分组，以连续容器、图标和章节标题组织信息。
- 素材：四张自绘 SVG 场景插画，包含夜行列车、城市黄昏、海岸、钢琴房；属于原创示例封面，不代表实际唱片或在线元数据。

## 设计依据和自定义边界

依据 Google Material 3 / Expressive 及 m3-expressive 的 `expressive-tactics.md`、`tokens.md`、`component-tokens.md`、`shape.md` 和 `components/buttons.md`，并沿用 [01 的规范与资源来源](../prototype-v1/README.md#google-规范与产品决策)。

- 使用大小、形状、颜色角色、强调排版和逻辑分组引导注意；主要视觉重点放在播放页。
- 字体使用 display medium 45/52、display small 36/44、headline large 32/40、headline medium 28/36、title large 22/28 等角色；标题强调字重为 Medium，列表重要标题和操作标签使用对应 Bold 角色。
- 播放页主按钮高度参考 Compose `ButtonLarge` 的 96 dp token，圆形 / 方形状态与按压形状依据按钮指导；主按钮文字映射到 headline small 24/32 是本版的自定义决定。本原型以 CSS px 表达 dp 的审核比例，不代表原生实现。
- 空间变化使用技能提供的 web spatial 曲线回退，透明度使用无过冲 effects 曲线。减少动态效果偏好下关闭动画。
- 非对称封面画框的尺寸、单角裁切、列宽、分组布局和信息架构属于 RxPlayer 的产品提案，不声称是 Google 标准形状或官方音乐播放器模板。嵌套画框半径按外框减内边距处理。
- 深浅色角色和本地字体复用原型 01；02 默认深色用于本轮审阅，仍可切换浅色，不代表正式默认主题已定。
- Rhythm 仅帮助理解用户希望的表现强度，不复制其截图、封面、字体、布局或实现。

文件组织：`index.html`、`expressive.css`、`prototype.js` 和 `assets/*.svg` 是本版内容；基础 CSS、本地字体和字体许可位于 `../prototype-v1/`，预览时需从 `design/` 根目录提供服务。
