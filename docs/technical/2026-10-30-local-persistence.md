# M2 首批本地持久化与恢复

日期：2026-10-30。授权范围见 [实现计划](../superpowers/plans/2026-10-30-local-persistence.md)。

## 已实现

- AndroidX Bundled SQLite 2.7.1，共享 SQL、事务与版本检查。版本 1 表为 `items`、`tracks`、`favorites`、`recent`、`queue`、`app_state`。
- 收藏按来源内容身份保存；历史、队列及顺序使用 BVID / CID / 分 P 元数据，不保存 AudioStream、播放直链或请求头 / 凭据。
- 恢复当前队列项及位置、随机 / 列表循环、音量、明暗和封面配色设置。未选择过主题时跟随系统，显式选择后保留原选择。当前项已不在队列时不复活已移除项。
- 恢复不调用音频解析或加载引擎，不自动出声；点击播放才解析新音频地址。已结束曲目再次播放从头开始。
- 普通播放推进满 5 秒更新检查点；拖动、暂停和正常关闭保存精确目标 / 当前采样位置。Windows 拖动异步提交给 mpv 时保留目标，确认完成后再恢复引擎位置，避免旧轮询覆盖恢复点。
- Windows 关闭窗口先暂停并保存后退出；Android 退后台触发暂停保存，组合销毁也尝试最终保存。突然强杀 / 断电可能损失尚未提交的最近检查点；保存采用完整事务。
- Android 路径为私有 `files/library.db`，Windows 为 `%LOCALAPPDATA%/RxPlayer/library.db`。数据库操作位于 IO 调度器，通过互斥串行访问。
- 数据读取失败仅以内存继续并提示，禁用本次会话写入以保留原库；写入失败短提示。未知高版本 / 非空无版本数据库拒绝重建；未来结构升级需明确增加迁移，当前未宣称跨产品版本升级已验证。
- 设置中的恢复说明和勾选图标使用完整原型已有状态，未增加页面 / 布局 / 设计方案。
