# 歌曲信息补全正式接线

日期：2026-11-06。分支：`codex/song-metadata`。用户明确「确认，按此方案接入双端」，确认原型基线 `dc7316e`。本批只实施已确认的补全 / 回退流程，不重新设计播放页。

## 已实现

- 从具体分 P / 视频标题及有界简介提取歌名与演唱者；UP 主保留为发布者。明确唯一、完整演唱者集合及版本一致、时长相差不超过 2 秒时自动补全；现场 / 翻唱 / 串烧 / 调速 / 重制不自动套用。
- 原视频 / 具体 P 或候选标题中的中英文括号可能是别名或录音限定，因此不直接删掉后自动匹配。未知情况保持原视频，提供手动选歌；不为某一首歌添加例外白名单。
- 网易云匿名搜索、详情封面、同步 LRC；主歌词缺失时严格按完整题名 / 演唱者集合 / 版本 / 时长且唯一记录查询 LRCLIB。客户端标识、顺序请求、完成后至少 300 ms 间隔及 429 冷却已实现，不自动循环重试。仅纯文本时沿用无同步歌词布局。
- 同步 LRC 解析元信息、毫秒、多时间戳与 offset。可读歌曲数据与歌词分别回退；自动错误不打扰播放，主动查询失败使用已有 toast。
- 当前项的自动请求与手动面板独立取消 / ticket；手动应用重新检查已知版本、歌手和时长冲突。详情无法确认时允许保留人工选择的资料，但不套同步歌词。关闭 / 切歌后的迟到请求不覆盖新选择。
- 播放页、迷你播放器及双端系统媒体显示歌曲资料；源视频 / cid、真实时长、音频、队列 / 搜索 / 歌单中的源信息、进度与暂停意图保留。没有重新加载引擎来更换封面或歌词。
- 选择面板沿用确认稿，候选区分“歌词待查询”与已选的真实可用状态；恢复原信息后持久保存 opt-out。右上角更多图标由原型字体脚本同源导出。
- SQLite schema 3 → 4 新增独立歌曲记录表，保存元信息、外部歌曲 ID、解析歌词、封面 URL 与用户 opt-out；迁移不覆盖原视频表。此处缓存的是资料和歌词，**没有新增图片文件离线缓存**。
- 应用内图片失败回退原视频图；系统媒体共用有界缩略图加载器，主图 HTTP / 类型 / 大小 / 解码失败均尝试原视频图一次。系统图片上限 256 KiB，网易云请求 500×500 缩略图；复用现有平台解码器的尺寸约束并强制读取像素。Android 通过压缩 artworkData 更新系统元数据，避免要求系统自行猜测回退 URL；下载按当前图像 key 取消和隔离。

## 实际验证

使用 Temurin 17，运行：

```powershell
$env:RXPLAYER_METADATA_LIVE_TEST = '1'
./gradlew.bat :composeApp:desktopTest --tests '*SongMetadata*' --tests '*SystemArtworkTest' --tests '*LibraryStoreTest' --tests '*PlaybackRuntimeTest' --tests '*WindowsMediaSessionTest' --tests '*BilibiliBrowseStateTest' --tests '*BilibiliSourceTest' --tests '*PlaybackStateTest' --console=plain
```

最终 **99 项通过，0 失败 / 错误 / 跳过**：规则 7、状态 8、资料源 12、系统图片 4、SQLite 9、runtime 8、Windows 媒体 3、浏览状态 5、Bilibili 来源 12、播放状态 13、在线播放状态 16、两项显式联网探针各 1。

红绿记录：模型 / 状态 / schema 缺失先失败；网络空实现有 10 个预期断言失败后实现。时间测试曾混用真实 / 虚拟时钟，已统一注入时钟与 MockEngine dispatcher，未放宽时间断言。另补充并实际重现了额外演唱者 / 版本、未知括号、详情变化及损坏图片错误后修复。

最终 Kotlin 联网样本：视频 `BV1Ekub6zE3D` → 线索歌手李佳薇 → 歌曲 `3399839173`；目录标题含「你我怎么两清」括号副标题，因此**自动匹配拒绝该歧义，探针明确选择对应候选**后取得 62 条带时间戳记录、24057 字节封面，实际平台解码和像素读取通过。原视频身份 / 时长不变。该结果不代表所有视频的自动识别率或实际听感同步已验收。

JS 语法、Git 空白检查通过；唯一完整原型更新确认状态及缓存标记。网络子任务完成规格 / 代码质量两阶段审查；整体审查提出的未知版本、候选歌词状态和系统封面回退均已修复并定向复核通过。

## 验证边界与交付

- 定向测试包含共享 / Windows 代码编译，不是正式分发构建或 UI 验收。Windows 使用已编译版本启动供用户审核，启动结果记录在进度与最终回复。
- 按用户最新执行约定，没有额外构建 / 安装 Android APK、没有安装独立测试包。本批 Android 源码接线完成，但 Android 平台编译、真机通知 / 锁屏与听感同步未验证。
- 没有自动逐页操作原生 UI，没有扩展完整流程回归。第三方接口覆盖率、实际歌词时间偏移及长时间离线恢复仍需用户集中验收；无可用匹配或歌词时不阻断音频。
- LRCLIB 严格回退可能不命中含别名的不同标题记录，此时不填充猜测歌词。首批无纯文本专用展示、逐字 / 翻译、偏移编辑、ASR 或音频指纹。
- Media3 artworkData API 依据 [Android 官方文档](https://developer.android.com/reference/androidx/media3/common/MediaMetadata.Builder)；本轮未据此宣称 Android 编译或运行通过。
- 当前已授权范围按仓库约定提交推送并合并 main；准确提交 / 合并结果以 Git 历史和最终交付回复为准。
