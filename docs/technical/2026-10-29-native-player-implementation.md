# 已确认播放页的原生源码交付

日期：2026-10-29。分支：`codex/native-player`。基点：`f375a93`。

## 范围与实现

设计依据为正常布局 `774a6d6` 与播放状态 `608ddb2`，见 [原生规格](../superpowers/specs/2026-10-29-m1-player-native-spec.md)。本轮仅实现其等价代码，不重新设计搜索、音乐库或账号页。

- Android：有歌词时封面铺到真实状态栏下方，压暗并渐隐到 surface；歌词五槽、队列在收藏左边、底部五按钮控制。无歌词使用独立封面及两行分区控制卡。
- Windows：左侧播放控制，右侧歌词；宽窗口队列替换右栏，窄窗口使用模态侧面板。单一队列模型和同一内容组件在不同宿主之间切换。
- 播放器展开为独立全页，背景列表不再保留隐藏的焦点目标；收起后列表位置与播放状态保留。Android 返回与 Windows Esc 优先关闭队列，随后关闭播放页；焦点恢复到入口。
- 准备、缓冲、更新地址只在原进度轨道显示不定效果；错误使用单条 3 秒短提示，重试通过主操作执行；未知时长显示 `—:—`。
- 真实引擎完成事件驱动队列推进。顺序模式末尾静默停止，主按钮恢复播放图标；用户再播放从头准备。随机模式生成稳定的一次排列，按该顺序到末尾停止；列表循环保留。
- 播放、暂停、拖动、音量及资源加载仍使用现有本地 WAV 适配器。准备取消 / 快速切歌以 Job 取消、串行资源切换与选择代次控制，旧结果不能覆盖当前曲目。后台暂停后，晚到的选择不会恢复自动播放。
- 按确认封面 SVG 生成三张 720 × 720 本地 PNG，使用原型 MCU 输出的成对角色；应用导航保持品牌色。生成脚本为 `scripts/generate-native-player-assets.cjs`，需要 Node.js / sharp，未增加运行时网页或远端素材请求。

## 平台与可访问性

- 系统状态栏 / 手势区使用真实 Insets，未复制原型的模拟手机外壳、固定上延量和状态栏文字。
- 保留至少 48 dp 的按钮目标、角色色、切换语义、进度名称和状态、键盘悬停提示及焦点恢复。输入框和 Slider 的空格不会触发全局播放。
- Android 读取并监听动画时长缩放；Windows 通过 JNA `5.17.0` 只读调用 `SystemParametersInfoW(SPI_GETCLIENTAREAANIMATION)`，每秒读取一次系统动画偏好。关闭动画时缓冲轨道保持静态、按钮 / 歌词颜色直接切换。
- Windows API 常量与 BOOL / UINT / PVOID 映射核对了 [Microsoft 官方说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-systemparametersinfow)，依赖版本核对了 [JNA 官方发布](https://github.com/java-native-access/jna/releases/tag/5.17.0)。这不是原生加载或分发验证。

## 演示和技术边界

- 三来源标签仍为本地演示分类，未把 WAV 引擎替换为在线流媒体。`AudioPlayer` 的缓冲、失效与权限错误契约已连接 UI，但当前本地后端不会伪造这些网络状态。
- 地址恢复当前为同一资源的重新加载及位置 / 意图保留；真实临时 URL 更新、请求头、账号权限和账号设置迁移仍属于音源接入阶段，未宣称已完成。
- 夜航歌词是单独标明的本地布局夹具，时间点在 16 秒演示音频范围内；不返回给真实在线内容，也不冒充识别或真实在线歌词。
- 收藏、队列、配色偏好仍为内存状态；后台服务、系统媒体会话、持久化与可分发引擎包不在本轮实现范围。
