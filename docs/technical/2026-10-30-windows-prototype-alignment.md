# Windows 主页面原型对齐记录

## 授权与范围

用户对比 Windows 技术样例与原型 03 后要求“改”（2026-10-30）。以 `25c3919` 中的 `design/prototype-v3` 搜索结构和 C 浮岛为实现基线，复用 `codex/desktop-transport-review`。本次为已有原型的等价迁移，不重新设计、不将原型中的虚构在线数据接入应用。

## 源码变更

| 对照区域 | 本次实现 |
|---|---|
| 导航 | Windows 独立桌面路径，搜索 / 音乐库 / 设置；导航贯穿内容区左侧，底栏不跨入导航 |
| 搜索页 | 移除旧品牌标题和大横幅；页标题 / 说明、填充搜索框、清空 / 执行、三音源分组、最佳匹配 / 更多匹配 |
| 列表 | 连续圆角分组、分隔线、整行 hover、独立收藏 / 更多操作；播放与收藏继续使用原状态 |
| 队列 | 宽窗口右侧 320 dp 内嵌、窄窗口侧浮层；两种模式互斥，底栏始终在内容区 |
| 浮岛 | 对齐宽度比例和控制分组；暂停圆角 20 dp、播放圆角 28 dp、主图标 28 dp；其余图标改为同一 outlined 家族；音量滑块圆柄 16 dp |
| 返回上下文 | 桌面浏览状态在 App 中持有；展开播放页不会重置页面、逐音源查询和各页滚动位置 |
| 辅助页面 | 已有收藏以原型收藏摘要 / 分组列表呈现；已有明暗 / 封面跟随设置移至设置分组。未提供无效的账号连接按钮 |

上述布局尺寸沿用 RxPlayer 原型，是产品决策；颜色继续使用已与原型对应的品牌 / 封面角色。Android 使用原有首页、MiniPlayer 及默认播放按钮参数；展开播放器沿用已确认方案。

## 数据与未实现边界

- 应用仍仅有夜航、日光之间、环游三首原创本地音频，每个演示音源分类一首。搜索可输入 / 提交及逐源切换，没有真实在线请求。
- 每源一首时只显示最佳匹配；多于一首才显示更多匹配。收藏多首时可显示连续结果分组；不为了凑截图伪造在线结果。
- 本地样本时长为 16 秒，界面显示本地样本信息；不使用原型虚构的分钟数和艺术家代替实际资源。播放进度仍使用引擎返回时长。
- 歌单、最近播放持久化和账号接入尚未实现，音乐库 / 设置仍需后续完整功能审核。本轮不把这些能力或 Android 其他页面标记完成。

## 检查与验收

- 已完成针对性 Kotlin 语法解析、Git 空白检查和独立只读源码审查；无已发现的 Critical / Important 问题。
- 按用户“不默认构建”和“集中验收”的要求，本轮没有运行 Gradle、启动应用、操作设备或重走播放流程。
- **未编译、未进行新版本原生截图对照或运行验收。** 源码完成不等于已运行的旧窗口自动更新，也不等于整套 Windows 与原型已通过视觉验收。
- 后续集中验收重点：相同窗口尺寸 / 主题 / 曲目下对照搜索页和浮岛，检查队列开闭、搜索提交及播放器返回；不将旧版本的 9 项测试结果记为本轮新版本结果。
