日期：2026-10-30。复用 `codex/m1-feasibility`，合入当前 main 的 UI 实现和最新执行约定。本报告是技术证据收口，不代表整个 M1 或真实产品闭环通过。

## 新取得的结果

1. [Bilibili 自然到期记录](../evidence/m1/2026-10-30-bilibili-signed-expiry.json)：历史观察实际在 2026-10-29 16:48:16（北京时间）完成。过期前旧地址 206，deadline +30 秒后旧地址 403，同内容重新解析后新地址 206。此前结果仅留在仓库外，本次归档；不是今天重跑两小时得到的结果。
2. [YouTube 中断记录](../evidence/m1/2026-10-30-youtube-expiry-interrupted.json)：原报告停在 waiting，当前无对应观察进程。旧 URL 只存在原进程内存，不能恢复自然到期检查；结果明确为 interrupted_unobserved，不伪造过期失败或刷新通过。网易云标称 TTL 后旧地址仍可用的结论保持不变。
3. [Bilibili 边界运行](../evidence/m1/2026-10-30-bilibili-boundaries.json)：匿名搜索第 1 / 2 页返回不同内容；`BV14u41147YH` 共 36 个分 P，同一视频的 AV / BV 元数据一致；前两个分 P 的 cid 不同，各自解析 AAC / MP4 并取得 HTTPS Range 206。不可用 aid=1 业务码仍独立记录。本次旧搜索路径可用，不承诺网页私有接口长期稳定，也没有将 WBI 签名路径标为已实现。
4. [Windows 引擎隔离运行](../evidence/m1/2026-10-30-engine-isolation.json)：实际 exe SHA-256 与固定来源清单一致；只复制 mpv.exe 到新临时目录，子进程 PATH 仅 System32，没有 mpv / ffmpeg / VLC 外部程序；AppData 重定向到测试空目录，并关闭用户配置 / 脚本。原创 WAV 与 Bilibili 真实 HTTPS AAC 均初始化 WASAPI、推进 / 暂停 / 拖动 / 继续 / stop，退出码 0、IPC 管道消失。原始包位于仓库外，不修改全局环境。

隔离目录试验仅证明当前 Windows 主机无需 PATH 上额外播放器；**不等于另一台干净系统、最低系统或正式安装包验收**。所用第一方 CI 包仍是验证候选；[mpv 官方安装说明](https://mpv.io/installation/) 明确第一方 CI 构建主要用于测试。固定 hash 不会自动解决最终二进制 / 对应源码 / 许可证资料的分发问题。

python -B -m unittest discover -s scripts/m1 -p test_bilibili_boundaries.py -v
python -B scripts/m1/probe_bilibili_boundaries.py --output docs/evidence/m1/2026-10-30-bilibili-boundaries.json

输入归一化测试覆盖 BV / AV、HTTPS 视频链接分 P、外域 / 用户信息 / 非法分 P 拒绝；媒体请求只读 64 KiB。报告无签名 URL、原始响应、Cookie 或代理地址。没有修改正式应用代码、重新安装 Android 探针或重做四格式全量播放回归。
