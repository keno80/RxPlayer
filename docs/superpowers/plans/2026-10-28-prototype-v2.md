# 产品原型 02 修订计划

目标：按用户已授权的方向，提高播放主操作、内容图像、排版和分组的表现力，交付双端可点击原型供审核。

范围：复用 `codex/prototype-review`；保留原型 01，在 `design/prototype-v2/` 新增审核版本。共享 01 的基础样式与本地字体，02 单独维护页面表达和交互脚本。全部数据、账号和播放仍为本地模拟，不改 Compose 工程、不构建原生应用。

设计依据：Google M3 与 m3-expressive 的 tactics、tokens、shape、buttons 和 containment。Rhythm 帮助理解用户对表现力的期待，不复制其截图、封面、页面、字体或代码。播放页作为主要视觉重点；搜索强调查找任务；音乐库与设置强调逻辑分组。

- [x] 新增原创 SVG 场景封面，替换占位几何图形；明确素材属于本原型自绘插画。
- [x] 搜索最佳匹配、成组结果、音乐库收藏区和设置分组完成；保留三个音源和原有交互范围。
- [x] 双端播放页完成：非对称图片画框、主次尺寸对比、带标签的主播放操作、状态形状变化和面板进入反馈。
- [x] 浏览器检查两个平台、深浅主题、窄屏、焦点与核心交互；核对资源、颜色对比度和 Git 差异，不执行原生构建。
- [x] 更新审核说明和进度，准备本地原型 02 预览及审核分支交付。用户确认前不合并主分支。

交付动作：本轮按约定提交推送 `codex/prototype-review` 并打开原型 02；提交、远端与预览状态在实际操作后核对报告。

原型 02 的设计仍未被用户验收；本计划只记录制作与自检过程。

## 按钮修订

用户明确要求更大胆的按钮设计。范围保持在本版原型：大胶囊主播放与柔边切歌按钮形成主次对比；模式开关增加标签、颜色和形状状态；音乐库增加成对播放 / 随机操作；按钮组按压时宽度联动。Google standard button group 和 toggle 指导为依据，自定义轮廓、宽度和组合写明产品决策。
