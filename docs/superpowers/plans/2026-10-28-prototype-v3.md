# 原型 03：从用户任务重新设计

用户反馈：学习配色、组件运用与设计原则，避免照搬参考应用的文字按钮和装饰形状。授权范围是重新制作可审核设计，未批准产品实现或合并。

依据：Google Expressive UX 研究、M3 颜色系统、m3-expressive 的色彩 / 组件 / 布局 / 交互指导。研究强调注意力层级及熟悉交互；不将任何一个示例的文字、轮廓或构图视为必须复制的模板。

交付：新增 `design/prototype-v3/`，保留 01 / 02。复用既有本地演示状态和原创插画，独立重做样式与页面组织。使用 Material Color Utilities 生成蓝绿主色与暖杏第三色的静态角色方案，记录种子、版本和生成方式。
