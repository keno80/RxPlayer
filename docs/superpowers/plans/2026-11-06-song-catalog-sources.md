用户要求直接完整接入，范围为视频播放中的歌曲候选、封面及歌词，不增加 QQ / 酷狗音频播放入口。复用已确认面板，原型先同步来源数据，再进行等价接线；不新增组件、筛选模式或步骤。

选择按优先级聚合各源候选，而不采用“第一个来源有任意结果就停止”，避免高优先级的错误版本屏蔽后续正确版本。每个候选显示实际平台，来源与平台 ID 共同构成身份，原网易云缓存仍保留。自动选择在每个来源内要求唯一可靠版本，再按 QQ → 酷狗 → 网易云 → LRCLIB 取第一个合格项；用户明确选择优先于自动策略。
