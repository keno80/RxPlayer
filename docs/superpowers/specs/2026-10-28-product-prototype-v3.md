# 原型 03 设计与审核说明

状态：待用户审核。用户要求学习参考应用的配色与组件运用，并结合 Google 官方 UX / UI 文档重新设计；没有批准上一版或后续原生实现。

## 设计范围

新增 [原型 03](../../../design/prototype-v3/index.html)，保留 01 / 02。本轮以任务和注意力层级重新选择组件，熟悉的播放控制采用图标，搜索 / 歌单 / 异常动作按语义保留文字；不把参考应用的文案、特殊轮廓和构图作为模板。

- 应用主体保持静态品牌角色；播放强调色由当前四张本地封面实际像素经 MCU 预生成，切歌跟随，记录角色与种子。
- 当前播放：独立内容视图，图标填充主操作；Android 单列，按模拟歌词可用状态使用分区控制卡或横向控制条。Windows 使用整体居中的封面 / 曲目信息舞台，下方为完整横向进度及控制区。队列入口位于页面右上角，不展示歌词正文。
- 搜索：contained search、音源单选、最佳匹配与其余版本，保留垂直列表。
- 音乐库与设置：以内容和逻辑分组组织；必要文字与熟悉图标按情境搭配。

依据为用户指定的 [Google UX 研究](https://design.google/library/expressive-material-design-google-research)、[M3 颜色系统](https://m3.material.io/styles/color/system/overview) 与 m3-expressive 技能。具体组件选择、官方数值和自定义边界见 [原型说明](../../../design/prototype-v3/README.md)。

## 审核与交付

审核重点：主播放是否直观、封面色与按钮层级是否协调、两套控制布局是否适合各自情境、双端播放视图与返回路径是否自然，搜索和音乐库是否好用，深浅主题是否都成立。

完成浏览器自检仅表示交付的交互原型可审阅，不代表原生功能完成或设计已被用户认可。继续使用 `codex/prototype-review` 提交推送，用户确认前不合并；后续根据反馈集中修订。

此前追加的五按钮同排与示例歌词要求已完成并留作历史记录；最新要求改为下述两套控制，并移除歌词正文。可见“当前曲目”和状态提示继续保持移除。

用户指出队列侧栏与弹窗重复后，本版统一为自适应单队列面板：宽窗口直接使用可收起的完整侧栏，窄窗口 / 手机使用侧面板 / 底部面板，关闭返回原页面；播放页和侧栏同时可见时均可操作，真正的模态面板才限制背景和焦点。依据与自检记录见原型说明的队列交互修订章节。

用户进一步反馈按钮不协调，本轮结合新参考图与技能重做比例和分组：统一高度与中心线，主播放通过宽度 / 主色突出，切歌采用辅助色，模式按钮降低强调。保留图标语义和已确定的交互布局；具体尺寸、自定义边界及验证记录见原型说明。

最新修订：无歌词时使用“宽图标播放 + 下一首 / 上一首 + 进度”的两行控制卡；有歌词时使用进度在上、“上一首 / 后退 10 秒 / 图标播放 / 前进 10 秒 / 下一首”在下的横向控制条，模式按钮均在下方。两种模式均不展示歌词正文。按钮强调角色从当前封面像素生成，运行时按本地色板切换；原型尚未连接在线封面提取或歌词服务。审核工具栏可强制切换两套模式，默认随模拟曲目状态变化。设计仍待用户确认。

后续 PC 反馈修订优先于上述桌面编排：Android 保留两套布局，Windows 不再把手机控制卡放在右列，而是将封面与曲目信息整体居中，控制区横向展开到下方。模式、主播放 / 切歌、音量分布在控制区左 / 中 / 右，有歌词状态补充前后 10 秒按钮；单队列展开时舞台在剩余区域重新居中。标题尺寸、组件依据、定制数值和实际自检记录见原型说明的最新桌面章节。此版本继续在审核分支交付，不代表设计已获确认。
