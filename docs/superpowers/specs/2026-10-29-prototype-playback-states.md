## 状态与操作

| 场景 | 反馈 | 可用恢复与上下文 |
|---|---|---|
| 搜索等待 | 音源、关键词、不定进度、取消搜索 | 取消保留关键词；更改关键词或音源使旧请求失效；不改变当前播放 |
| 搜索失败 / 空结果 | 保留输入及音源，显示原因与重试 / 修改入口 | 重试经过等待，不清空当前曲目或队列 |
| 账号失效 | 内联说明匿名内容仍可搜索 | 查看账号；不把账号状态等同于所有内容均不可用 |
| 准备音频 | 原进度条内显示缓冲效果，未知时间显示 `—:—` | 主按钮取消准备，仍可切歌；取消结果不写入最近播放 |
| 播放 / 暂停 | 沿用暂定布局与图标主操作，无新增提示卡 | 进度及歌词可跳转；暂停保留位置 |
| 缓冲 | 原进度条内显示缓冲效果，已知位置保留且停止推进 | 主按钮暂停等待，停止自动继续；切歌不接受旧请求结果 |
| 播放失败 | toast：播放失败，点击播放按钮重试 | 主按钮重试当前曲目，或使用已有切歌按钮；保留队列和原位置 |
| 内容不可用 | toast：当前内容不可播放，可切换曲目或查看音源账号 | 主按钮可再次查看提示；账号入口位于设置，不承诺登录必然取得权限 |
| 地址失效 | toast：播放地址已失效，点击播放按钮重新获取 | 主按钮重新获取或使用已有切歌操作；保留队列及位置 |
| 更新地址 | 原进度条内显示缓冲效果，主操作取消 | 成功后沿用此前播放意图；之前暂停则保持暂停；取消保持失效且不播放 |
| 播放结束 | 顺序模式队列末尾直接停止，无卡片、无 toast，主按钮恢复播放图标 | 用户再次点击播放则从头准备；存在下一首则照常继续，既有列表循环模式保留 |

所有反馈、曲目、账号、歌词、搜索和时间均为本地模拟。提示不代表真实音源错误分类、账号鉴权或恢复已实现。模拟时长 900 / 1100 毫秒仅服务审核，不是性能指标。

## 设计依据与产品判断

- 使用 Google M3 / M3 Expressive 颜色角色和 `m3-expressive` 的 feedback、buttons、interaction 指导。未知进度使用不定进度，不显示编造百分比；一组任务保留一个进度指示器。
- 按用户明确要求，播放等待状态仅通过轨道表达，其他播放异常使用 toast，不保留状态卡。错误后的主按钮名称 / 图标和桌面迷你播放器状态仍保留语义，toast 消退后仍能重试或切歌。
- 主播放及缓冲动画继续使用当前封面派生的角色色；toast 沿用既有反色表面与文字、单条显示及 3 秒消退。该时长为原型产品决策，不宣称是官方 Snackbar 标准时长。
- 维持至少 48 CSS px 按钮目标、可访问名称、稳定 live region、禁用语义及可见键盘焦点；颜色不是唯一状态线索。
- 将不定缓冲效果放进既有进度滑块轨道、沿用 1.6 秒动画及模拟等待时间均为 RxPlayer 产品决定，不声称是原生 LoadingIndicator 或 Material Slider 的标准缓冲 API。
- 手机所有状态保留五槽歌词；不因反馈增加页面高度。桌面沿用左控制区独立滚动，右侧仍显示歌词或同一队列。

## 本轮验证与边界

- `track-feedback`：18 项检查通过，覆盖三类等待只显示轨道、不改变播放区布局、未知时长、取消不播放、三类异常仅 toast、toast 消退、更新地址保留暂停 / 位置、自然播放到队列末尾静默停止及用户再次播放从头准备。
- 四种宽度 × 两主题 × 两种歌词状态 × 八种播放状态共 128 组，通过无水平溢出、48 CSS px 可见按钮目标、缓冲轨道与原滑块区域对齐及减少动态效果静止检查；最后控制台无错误或警告。
- 已截图复核：[Android 轨道缓冲](../../evidence/prototype-states/android-track-buffer.png)、[Android 错误 toast](../../evidence/prototype-states/android-error-toast.png)、[Windows 轨道缓冲](../../evidence/prototype-states/windows-track-buffer.png)。未构建原生应用，当前仍待用户审核。

### 上一版状态卡方案的历史验证

- 27 项浏览器检查通过：等待取消、快速换曲最后选择生效、未成功曲目不进入最近播放、搜索不干扰播放、地址恢复保留位置 / 队列 / 暂停意图、取消后不自行播放、结束重播、未知时间、重试与完成后的焦点等。
- 320 / 390 CSS px 手机、900 / 1440 CSS px 桌面，各深浅主题、两种歌词状态和九种播放状态，共 144 组没有页面 / 播放层水平溢出、提示卡越界或小于 48 CSS px 的可见按钮目标。该检查不等于所有高度、文字缩放或真机布局均已验收。
- 四封面两主题八组采样，提示文字 / 主操作对比度最低约 6.45:1，错误图标最低约 5.29:1。减少动态效果偏好下不定进度动画为 `none`。
- 新增本地 Material Symbols 字体的 `link_off` 连字宽 24 CSS px，截图中为图形；最后控制台无错误或警告。
- 应用内浏览器实际打开 / Esc 关闭手机队列后，仍为同一曲目、失效状态、1:22 位置，焦点回到队列入口。手机地址失效与桌面失败已截图复核。
