# 产品原型 02 修订与审核说明

状态：待用户审核。用户要求先做原型供审核，且明确原型 01 表现力不足；本轮“开始吧”授权制作修订版，不代表批准任何产品设计或原生实现。

## 本轮设计

- 搜索、音乐库、设置三个入口继续作为待审核提案。搜索页强化标题和最佳匹配，仍保留完整结果与三个独立音源选择。
- 播放页作为主要视觉重点：原创场景封面、非对称图片画框、强调歌名、带文字的大尺寸播放按钮和较小的切歌按钮；播放 / 暂停反馈体现在按钮与画框形状上。
- Android 使用单列播放页和底部导航；Windows 足够宽时使用封面 / 控制双列和辅助队列，窄窗口转为单列播放面板并收起辅助队列。
- 音乐库增加收藏总览与播放收藏入口；音乐库列表、设置项目改为连续分组。设置仍保持外观、播放和音源账号的逻辑划分。
- 全部内容为演示，不接在线音源，不增加产品实现或原生构建范围。

依据 Google Material 3 / Expressive 及 m3-expressive 技能。具体 token 与自定义决策见 [原型说明](../../../design/prototype-v2/README.md)。Rhythm 用于理解用户期待的表现强度，未复制其 UI、素材或代码。
